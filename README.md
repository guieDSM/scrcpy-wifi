# scrcpy-wifi

Запуск [scrcpy](https://github.com/Genymobile/scrcpy) по Wi-Fi без кабеля (Android 11+, «Отладка по Wi-Fi»).
Скрипт сам находит телефон в локальной сети через mDNS, при первом запуске проводит сопряжение по коду,
подключается и открывает scrcpy с настройками под Wi-Fi.

## Установка

1. Распаковать `scrcpy-win32-v5.0.zip` (или новее) в папку `scrcpy\` рядом со скриптом,
   чтобы получилось `scrcpy\scrcpy.exe` и `scrcpy\adb.exe`. Папка в git не хранится.
2. На телефоне: Параметры → О телефоне → 7 раз нажать «Номер сборки»;
   затем Параметры → Система → Для разработчиков → **Отладка по Wi-Fi** → включить.
   ПК и телефон должны быть в одной сети.

## Запуск

- `scrcpy-wifi.cmd` — найти, подключиться, открыть экран телефона.
- `pair.cmd` — принудительное сопряжение (новый ПК, сброс доверия на телефоне).

Первое сопряжение: когда скрипт попросит, на телефоне в «Отладке по Wi-Fi» нажать
«Подключить устройство с помощью кода» и ввести показанный 6-значный код в консоль.
Дальше подключение идёт без кода.

Свои параметры scrcpy передаются после имени скрипта:

```
scrcpy-wifi.cmd --no-audio --turn-screen-off
.\scrcpy-wifi.ps1 -Ip 192.168.31.105 --max-size=1280
```

По умолчанию: `--video-bit-rate=8M --max-size=1920 --max-fps=60`. Если по Wi-Fi картинка
дёргается, уменьшить до `--video-bit-rate=4M --max-size=1280`.

## Если не находит

- Экран телефона должен быть включён, «Отладка по Wi-Fi» — активна (после перезагрузки или смены сети выключается).
- Сети с изоляцией клиентов (гостевые, публичные) mDNS и прямые соединения блокируют.
- VPN на ПК может перехватывать локальную сеть; адрес можно задать вручную: `-Ip 192.168.x.x`.
