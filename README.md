# scrcpy-wifi

Экран Android-телефона на компьютере с Windows **по Wi-Fi, без кабеля**: видно экран,
можно управлять мышью и клавиатурой, звук идёт на ПК. Внутри — [scrcpy](https://github.com/Genymobile/scrcpy),
этот репозиторий только делает подключение в один клик.

Нужно: Windows 10/11, Android 11 или новее, телефон и ПК в **одной Wi-Fi сети**.

## Быстрый старт

### 1. Скачать

Зелёная кнопка **Code → Download ZIP** вверху этой страницы. Распаковать архив в любую папку
(не запускать прямо из архива).

### 2. Включить на телефоне отладку по Wi-Fi (один раз)

1. **Настройки → О телефоне** → 7 раз нажать на **«Номер сборки»**. Появится «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков** → включить **«Отладка по Wi-Fi»** и согласиться.

> На Samsung, Xiaomi и других пункты называются похоже, но могут лежать в другом месте —
> проще найти поиском в настройках: «номер сборки», «отладка по Wi-Fi».

### 3. Подключиться

Дважды кликнуть **`Подключить телефон.cmd`**.

- В первый раз скрипт скачает scrcpy (~11 МБ с официального GitHub, контрольная сумма проверяется).
- Затем попросит **сопряжение**: на телефоне в «Отладке по Wi-Fi» нажать
  **«Подключение с помощью кода подключения»** (точное название зависит от телефона), и ввести
  6 цифр в окно на компьютере. Это делается один раз.
- Откроется окно с экраном телефона. Закрыли окно — отключились.

Дальше каждый раз: включить на телефоне «Отладку по Wi-Fi» → `Подключить телефон.cmd`.

Если Windows спросит про брандмауэр для `adb.exe` — разрешить для частных сетей.

## Управление

| Что | Как |
|---|---|
| Назад | правая кнопка мыши |
| Домой | средняя кнопка мыши |
| Вставить текст с ПК | Ctrl+V |
| Выключить экран телефона, картинка остаётся | Alt+O |
| Повернуть | Alt+← / Alt+→ |
| Полный экран | Alt+F |

Остальное: [список сочетаний scrcpy](https://github.com/Genymobile/scrcpy/blob/master/doc/shortcuts.md).

## Если не работает

| Проблема | Что сделать |
|---|---|
| «Автоматически не нашёлся» | Экран телефона должен быть включён, «Отладка по Wi-Fi» — включена (после перезагрузки и смены сети она выключается сама). Можно ввести вручную «IP-адрес и порт» из того же экрана. |
| Не находит совсем | Гостевые и публичные сети (кафе, общежития) часто блокируют такие соединения. VPN на ПК тоже может мешать — выключить на время. |
| Сопряжение не проходит | Запустить `Сопрячь заново.cmd`, код вводить, пока окно с кодом открыто на телефоне. |
| Картинка дёргается | В `Подключить телефон.cmd` можно добавить параметры, см. ниже: меньше качество — плавнее. |
| Окно «Windows защитила ваш компьютер» | «Подробнее» → «Выполнить в любом случае». Файлы `.cmd` и `.ps1` — обычный текст, их можно открыть Блокнотом и прочитать. |

## Для продвинутых

```powershell
.\scrcpy-wifi.ps1                                  # обычный запуск
.\scrcpy-wifi.ps1 -Pair                            # сопрячь заново
.\scrcpy-wifi.ps1 -Ip 192.168.1.20                 # если в сети несколько телефонов
.\scrcpy-wifi.ps1 --video-bit-rate=4M --max-size=1280   # плавнее на слабом Wi-Fi
.\scrcpy-wifi.ps1 --no-audio --turn-screen-off     # без звука, экран телефона погашен
```

По умолчанию: `--video-bit-rate=8M --max-size=1920 --max-fps=60`. Все параметры scrcpy:
[документация](https://github.com/Genymobile/scrcpy#user-documentation).

## Что внутри

- `scrcpy-wifi.ps1` — вся логика: скачивает scrcpy закреплённой версии (v5.0.1) с проверкой SHA-256,
  ищет телефон в сети через mDNS (`adb mdns services`), делает `adb pair` и `adb connect`, запускает scrcpy.
- `Подключить телефон.cmd`, `Сопрячь заново.cmd` — запуск двойным кликом.
- Папка `scrcpy\` появляется после первого запуска, в репозитории её нет.
