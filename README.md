# scrcpy Wi-Fi

Экран Android-телефона на компьютере с Windows **по Wi-Fi, без кабеля**: видно экран,
можно управлять мышью и клавиатурой, звук идёт на ПК. Внутри — [scrcpy](https://github.com/Genymobile/scrcpy);
это маленькое приложение находит телефон в сети, сопрягает его и открывает экран в один клик.

Нужно: Windows 10/11, Android 11 или новее, телефон и ПК в **одной Wi-Fi сети**.

## Быстрый старт

### 1. Скачать

Справа на этой странице **Releases** → последняя версия → **`scrcpy-wifi.exe`**.
Это один файл, установка не нужна — можно запускать хоть из «Загрузок».

> Windows может показать «Windows защитила ваш компьютер»: у программы нет платной подписи.
> Нажмите «Подробнее» → «Выполнить в любом случае». Исходный код — в этом репозитории, exe собирается
> на GitHub Actions.

### 2. Включить на телефоне отладку по Wi-Fi (один раз)

1. **Настройки → О телефоне** → 7 раз нажать на **«Номер сборки»**. Появится «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков** → включить **«Отладка по Wi-Fi»** и согласиться.

> На Samsung, Xiaomi и других пункты называются похоже, но могут лежать в другом месте —
> проще найти поиском в настройках: «номер сборки», «отладка по Wi-Fi».

### 3. Подключиться

Запустить `scrcpy-wifi.exe`.

- В первый раз приложение скачает scrcpy (~11 МБ с официального GitHub, контрольная сумма проверяется).
- Найдёт телефон в сети. Если компьютер новый — попросит **сопряжение**: на телефоне в «Отладке по Wi-Fi»
  нажать **«Подключение с помощью кода подключения»** и ввести 6 цифр в приложении. Это один раз.
- Откроется окно с экраном телефона. Закрыли окно — отключились.

### 4. Ярлык (один раз)

В окне программы нажать **«Добавить ярлык на рабочий стол и в «Пуск»»**. Программа скопирует себя в
`%LOCALAPPDATA%\scrcpy-wifi` и создаст ярлык **«scrcpy Wi-Fi»** на рабочем столе и в меню «Пуск»
(можно найти поиском, закрепить на панели задач). Скачанный exe после этого можно удалить.

Дальше каждый раз: включить на телефоне «Отладку по Wi-Fi» → открыть ярлык «scrcpy Wi-Fi»,
экран откроется сам.

Новая версия: скачать новый `scrcpy-wifi.exe`, запустить и нажать «Обновить ярлык на эту версию».

Если Windows спросит про брандмауэр для `adb.exe` — разрешить для частных сетей.

## Управление в окне экрана

| Что | Как |
|---|---|
| Назад | правая кнопка мыши |
| Домой | средняя кнопка мыши |
| Вставить текст с ПК | Ctrl+V |
| Выключить экран телефона, картинка остаётся | Alt+O |
| Повернуть | Alt+← / Alt+→ |
| Полный экран | Alt+F |

Остальное: [сочетания клавиш scrcpy](https://github.com/Genymobile/scrcpy/blob/master/doc/shortcuts.md).

В приложении в «Настройках экрана»: качество (плавно / баланс / максимум), звук, гасить экран телефона,
не давать телефону засыпать, окно поверх остальных, автооткрытие экрана. Настройки запоминаются.

## Если не работает

| Проблема | Что сделать |
|---|---|
| «Ищу телефон в сети…» и ничего | Экран телефона должен быть включён, «Отладка по Wi-Fi» — включена (после перезагрузки и смены сети она выключается сама). Можно ввести вручную «IP-адрес и порт» с того же экрана телефона. |
| Не находит совсем | Гостевые и публичные сети (кафе, общежития) часто блокируют такие соединения. VPN на ПК тоже может мешать — выключить на время. |
| Сопряжение не проходит | Вводить код, пока окно с кодом открыто на телефоне. Код каждый раз новый. |
| Картинка дёргается | «Настройки экрана» → качество «Плавно». |
| Что-то другое | Раскрыть «Журнал» в приложении → «Скопировать» и прислать. |

## Без приложения: скрипт

В папке [`scripts/`](scripts) — то же самое в виде скрипта PowerShell (`Подключить телефон.cmd`),
для тех, кому удобнее консоль или нужны свои параметры scrcpy:

```powershell
.\scripts\scrcpy-wifi.ps1 -Pair                         # сопрячь заново
.\scripts\scrcpy-wifi.ps1 -Ip 192.168.1.20              # если в сети несколько телефонов
.\scripts\scrcpy-wifi.ps1 --no-audio --turn-screen-off  # любые параметры scrcpy
```

## Разработка

- `src/` — приложение на Rust ([egui](https://github.com/emilk/egui)): `install.rs` скачивает scrcpy
  закреплённой версии (v5.0.1) с проверкой SHA-256 в `%LOCALAPPDATA%\scrcpy-wifi`, `adb.rs` — обёртка над adb
  (`mdns services`, `pair`, `connect`), `main.rs` — окно.
- Сборка: `cargo build --release`. CI собирает exe на каждый пуш; тег `v*` публикует релиз.
